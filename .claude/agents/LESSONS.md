- [2026-07-03] connor · confirmed · CDN-vendored client-side libs (www/vendor/*) deploy clean on Connect IF: (1) each file is git-committed AND in the manifest files-map with a checksum that matches the on-disk md5 (verify with md5sum vs the manifest checksum — a stale hash = silent bundle mismatch), (2) referenced ONLY via tags$script/tags$link in ui.R with a RELATIVE href/src ("vendor/x", no leading slash — a leading /vendor/ breaks behind Connect's per-app URL prefix), (3) nothing in the R boot path (global.R/server.R/R/*) fetches them. Vendored files are client-side only, so they are NOT R packages and never touch the terra/GDAL compile. onerror data-cdn fallback stays dormant when local files 200.
- [2026-07-03] fable · confirmed · QC-flag lifecycle: a possible-error flag (±5·MAD) is not a dead-end tooltip. ONE shared rule (`.is_meas_outlier` + `species_adult_values` in helpers.R) feeds ALL surfaces so a value flagged in one place is flagged in every place — the species-table ⚠, the QC modal (tags now DRILL to the animal's dossier via `pick_individual` + `input$qcDrillTag`), a red ⚠ ring on measPlot + morphoPlot, an inline ⚠ in capHistory, AND the Chonk exclusion (`compute_condition` drops flagged weights before `percent_rank` so one bad reading can't skew a rank or pollute the species pool; the "heaviest" annotation skips a flagged high outlier too), with the exclusion disclosed in the chonk caption. The rule: a flagged value must be traceable to its source, marked everywhere it's drawn, excluded from every derived metric, and the exclusion disclosed.
- [2026-07-20] connor · confirmed · The "committed manifest must equal the CI-regenerated manifest" gate is only STABLE if `write_manifest.R` is byte-deterministic. Source-built packages carry a wall-clock `Built` field that changes every compile, so a faithfully-promoted manifest can still come back red. Make it deterministic: strip `Built` from each source-built pkg, canonicalize the geo pins to the deployable lane (`Source`="CRAN", `Repository`="https://cran.r-project.org"), freeze floating RSPM aliases by TARGETED text-substitution (`readLines`/`gsub`/`writeLines`) — NEVER a `jsonlite` reserialize (it mangles `writeManifest`'s canonical format AND destroys the exact `url::` tarball refs in `RemotePkgRef`) — and pin `platform`=4.5.2 + `locale`="C". Then CI can "regenerate twice, require identical bytes" and a read-only `verify_manifest.R` twin makes "committed == regenerated" enforceable without granting write. (Diagnosed from the ChatGPT cover rework: veg's one Living-Poster PR burned 13 CI runs, partly on Built-timestamp drift.)
- [2026-07-20] neonize · gap · The manifest/derived-bytes gate + `permissions: contents: read` + an agent with NO local R = a mandatory MERGE LOOP, and it is what "ChatGPT failed merges over and over" actually was (not a git error — every one of those PRs did merge). Each runtime edit shifts a checksum, so `git diff --exit-code -- manifest.json` fails BY DESIGN; the only way to a valid manifest is push→let CI build it→download the VALIDATED `*-manifest-<sha>` artifact (never the `-UNVALIDATED-` one)→commit byte-for-byte→re-run the exact head→merge. `cancel-in-progress: true` cancels the run on any quick re-push, and each run source-compiles terra/sf (45–100 min). Owner-level fixes: (a) a deliberate `workflow_dispatch` "regenerate & commit manifest" job (keeps write restricted, kills the round-trip), or (b) give the agent env the pinned R+GDAL-3.4.1 toolchain so the manifest regenerates in one commit. Do NOT auto-commit on every PR — it breaks the "write only to the final restricted publisher" boundary. Also: the suite is split `main`/`master` (Driver-Cascade is `master`); standardize or an agent assuming `main` gets base-branch push failures on 1 repo in 3.
