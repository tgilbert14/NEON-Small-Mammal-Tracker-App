How it stays honest
Every site loads from a pre-bundled snapshot so there are no live-API waits, and every view leads with transparent, well-sourced methods. Abundance is Minimum Number Known Alive (Krebs 1966) and catch-per-effort, with closed-capture detection-corrected estimates (Schnabel / Chapman) shown only when within-bout recaptures make them stable, and never below the number handled. Diversity is Hill numbers over distinct individuals, so a frequently-recaptured animal isn't double-counted. Body size is read as a QC / morphometric map, not a body-condition index. Each animal keeps one tag for life, so multi-year careers are treated as the real long-lived animals they are, and only the rare impossible history (a tag at two plots on one day) is flagged.
